# Legacy scripts (not used for the reported results)

These are earlier development scripts kept for transparency: the numbered pipeline
(01-15) built around downloadable ClinVar/ClinGen/Orphadata sources, an early
learning-to-rank driver, and a draft schematic generator. They are not maintained and
are not needed to reproduce any table or figure in the manuscript. See the top-level
`README.md` for the scripts that are.
